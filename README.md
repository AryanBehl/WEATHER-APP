# 🌦️ Weather App – Real-Time Weather Checker

A simple and interactive **Weather App** built using **HTML, CSS, and JavaScript**.
It fetches real-time weather data using an external API and displays temperature, city name, and weather conditions.

---

## ✨ Features

* 🔍 Search weather by city name
* 🌡️ Real-time temperature display
* 🌤️ Weather condition description
* ⚡ Fast API-based data fetching
* 🎨 Clean and simple UI

---

## 🛠️ Tech Stack

* HTML5
* CSS3
* JavaScript (Vanilla JS)
* Weather API (OpenWeather API)

## ⚙️ How It Works

* User enters a city name
* JavaScript sends request to OpenWeather API
* API returns weather data in JSON format
* Data is displayed dynamically on the UI
